## [0.1.0] - 2025-01-01

### 🚀 Initial Development Release

- Core ECS architecture and engine loop
- WebGPU-based rendering hardware interface (RHI)
- Render graph system for flexible pass management
- Input handling subsystem
- Scripting bindings
- Editor scaffolding
- Devtool CLI for configuring, building, and formatting the project
- Shader infrastructure with Slang support
- CI pipelines for automated builds and formatting checks
- Automated PR labeling via GitHub Actions
- Documentation generation with Doxygen
